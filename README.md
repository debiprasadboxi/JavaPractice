# JavaPractice Repository

A comprehensive practice repository covering **Java 8 through Java 21** features, with a strong focus on concurrency, functional programming, and modern language enhancements.

---

## 📚 Weekly Learning Plan

### Week 1: Java 8, 9–21 Mastery + Concurrency

- **Day 1: Streams & Lambdas**
  - filter, map, reduce, collect

- **Day 2: Optional & Date/Time**
  - Optional, LocalDate, Instant

- **Day 3: Functional Interfaces & CompletableFuture**
  - Deep dive into FI, async patterns

- **Day 4: Java Memory Model & Garbage Collection**
  - Heap, GC algorithms, tuning

- **Day 5: Concurrency Part 1**
  - Threads, synchronization, locks

- **Day 6: Concurrency Part 2**
  - ExecutorService, Fork/Join framework

- **Day 7: Concurrency Part 3 + Review**
  - Atomic classes, ConcurrentCollections
